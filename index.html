Why hybrid? Your words stay yours.

  1. On-device first. Mood, tags and a one-line summary are computed by Gemini Nano in this browser. The raw text of your entry never leaves the device for these tasks.
  2. Cloud only for the big picture. The weekly insight is generated in the cloud — but only from the short on-device summaries, never from your raw entries.
  3. You choose. In Settings you can force on-device only, cloud only, or let Daywise decide per task.

AI features need a Firebase project. The full step-by-step is in the README (section “Connect Firebase”). In short: create a project in the Firebase console → enable AI Logic (Gemini Developer API) → enable Anonymous sign-in, Firestore, Remote Config and App Check → paste the web config into js/firebase-config.js.
